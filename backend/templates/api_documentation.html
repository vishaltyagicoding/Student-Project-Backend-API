🔐 Authentication APIs

POST Register New User

/api/auth/register/

Create a new user account

Request Body:

email (string) *required - User email address
username (string) *required - Unique username
password (string) *required - Password (min 8 characters)
password2 (string) *required - Password confirmation (must match password)
first_name (string) - First name
last_name (string) - Last name

Example Request:

{ "email": "user@example.com", "username": "johndoe", "password": "SecurePass123", "password2": "SecurePass123", "first_name": "John", "last_name": "Doe" }

POST Login

/api/auth/login/

Authenticate user and receive JWT tokens

Request Body:

email (string) *required
password (string) *required

Example Response:

{ "access": "eyJ0eXAiOiJKV1QiLCJhbGc...", "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc...", "user": { "id": 1, "email": "user@example.com", "username": "johndoe" } }

POST Refresh Token

/api/auth/token/refresh/

Get new access token using refresh token

Request Body:

refresh (string) *required - Refresh token

POST Logout

/api/auth/logout/

Blacklist refresh token and logout user

Headers:

Authorization (string) *required - Bearer <access_token>

Request Body:

refresh (string) *required - Refresh token to blacklist

POST Verify OTP

/api/auth/verify-otp/

Verify email with OTP and activate account

Request Body:

email (string) *required - Registered email
otp (string) *required - 6-digit OTP from email

Example Request:

{ "email": "user@example.com", "otp": "123456" }

Success Response:

{ "detail": "Email verified successfully.", "user": {...}, "access": "eyJ0eXAiOiJKV1QiLCJhbGc...", "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc..." }

POST Resend OTP

/api/auth/resend-otp/

Request a new OTP if expired or not received

Request Body:

email (string) *required - Registered email

Example Request:

{ "email": "user@example.com" }

👨‍🎓 Students APIs

GET List All Students

/api/students/students/

Get paginated list of all students

Query Parameters:

page (integer) - Page number (default: 1)
search (string) - Search by name, email, or student_id
college (integer) - Filter by college ID
ordering (string) - Sort by field (e.g., first_name, -created_at)

POST Create Student

/api/students/students/

Create a new student (automatically sends welcome email)

Request Body:

first_name (string) *required
last_name (string) *required
email (string) *required - Unique email
student_id (string) *required - Unique student ID
college (integer) - College ID
course (integer) - CollegeCourse ID
branch (integer) - CollegeBranch ID

Example Request:

{ "first_name": "John", "last_name": "Doe", "email": "john.doe@example.com", "student_id": "STU001", "college": 1, "course": 1, "branch": 1 }

GET Get Student Details

/api/students/students/{id}/

Retrieve detailed information about a specific student

PUT / PATCH Update Student

/api/students/students/{id}/

Update student information (Owner or Admin only)

DELETE Delete Student

/api/students/students/{id}/

Delete a student (Owner or Admin only)

GET Search Students

/api/students/students/search/?q={query}

Advanced search across student records

Query Parameters:

q (string) *required - Search query

POST Send Bulk Email (Admin Only)

/api/students/students/send_bulk_email/

Send email to multiple students

Request Body:

student_ids (array) *required - Array of student IDs
subject (string) *required - Email subject
message (string) *required - Email message

POST Bulk Create Students

/api/students/students/bulk_create/

Create multiple students in a single request

Request Body:

students (array) *required - Array of student objects

Example Request:

{ "students": [ { "first_name": "John", "last_name": "Doe", "email": "john@example.com", "student_id": "STU001", "college": 1, "course": 1, "branch": 1 }, { "first_name": "Jane", "last_name": "Smith", "email": "jane@example.com", "student_id": "STU002", "college": 1, "course": 1, "branch": 1 } ] }

Success Response:

{ "success": 2, "failed": 0, "created_students": [ { "index": 0, "student_id": "STU001", "email": "john@example.com", "id": 1 }, { "index": 1, "student_id": "STU002", "email": "jane@example.com", "id": 2 } ] }

📋 Additional Information

Response Format

All API responses follow a consistent format:

{ "count": 100, "next": "http://api.example.com/students/?page=2", "previous": null, "results": [...] }

Error Responses

Error responses include status code and error details:

{ "error": "Error message", "detail": "Detailed error description" }

Common HTTP Status Codes:

200 - Success
201 - Created
400 - Bad Request
401 - Unauthorized
403 - Forbidden
404 - Not Found
500 - Internal Server Error

Pagination

List endpoints support pagination with the following parameters:

page - Page number (default: 1)
page_size - Items per page (default: 10, max: 100)

Filtering & Search

Most list endpoints support:

search - Full-text search across relevant fields
ordering - Sort results (prefix with - for descending)
Field-specific filters (e.g., college=1, branch=2)

⚡ Rate Limiting & Best Practices

Rate Limits

API requests are rate-limited to ensure fair usage:

Authenticated users: 1000 requests/hour
Unauthenticated users: 100 requests/hour

Rate limit headers are included in responses:

X-RateLimit-Limit: 1000 X-RateLimit-Remaining: 999 X-RateLimit-Reset: 1640000000

Best Practices

✓ Always use HTTPS in production
✓ Store tokens securely (never in localStorage for sensitive apps)
✓ Implement token refresh logic
✓ Handle errors gracefully
✓ Use pagination for large datasets
✓ Cache responses when appropriate
✓ Validate input on client side before sending

Email Notifications

The system automatically sends emails for:

📧 New student registration (welcome email)
📧 Student information updates
📧 Bulk emails from admin

All emails are processed asynchronously using Celery.
